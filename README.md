# wnb2026-Kukla-Misztak

Zespół tworzą Michał Kukla oraz Emilia Misztak

Zajęcia z wprowadzania do narzędzi bioinformatycznych będą skupiały się na stworzeniu potoku Snakemake który z pliku DArTseq oraz genomu referencyjnego tworzy plik VCF, który zawiera informacje o przynależności sondy do odpowiadającego jej miejsca w genomie.
